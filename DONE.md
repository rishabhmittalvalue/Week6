# Definition of done

What must be true for each page, one sentence per line, under its heading. Plain English, no
Ruby. Write what someone looking at the page could check: what must it show, and what must be
right about it?

This file is yours. Your agent reads it and writes one test for each sentence, named with that
sentence. It doesn't write here. Whether every sentence got its test is yours to check.
